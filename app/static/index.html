Загрузите видео, чтобы увидеть результат анализа.
Анализ занимает от 20 секунд до 4 минут в зависимости от длины ролика.

Как сопоставляются правила и видео

Сервис каждые 1,5 с читает состояние рабочего места (кассир на месте, кто за стойкой, что лежит на столе и в руках кассира, экран, сейф) и по изменениям состояния находит события. Для каждого типа события заранее выбраны пункты нормативных актов РК; цитаты взяты дословно из официальных текстов (adilet.zan.kz), модель ссылки не придумывает. Нарушения, для вывода о которых нужны невидимые на видео данные (проводки, сверки), не утверждаются.

API для автоматической проверки

Доступ по ключу в заголовке X-API-Key. Обработка асинхронная, в два шага.

МетодПутьНазначение
POST/api/v1/analyzeЗагрузить видео .mov (multipart, поле file). Ответ: {"job_id", "status": "processing"}
GET/api/v1/jobs/{job_id}Статус processing / done / failed и результат
GET/api/v1/healthГотовность модели и число задач в работе

Формат результата

      
{
  "job_id": "3f2a9c1e",
  "status": "done",
  "verdict": "violation",            // или "no_violation"
  "violations": [
    {
      "type": "Название типа нарушения",

}

      
Видео обрабатывается не дольше 5 минут: при перегрузке сервис снижает детализацию анализа,
        а по истечении лимита возвращает результат основного детектора (поле partial_result: true).
